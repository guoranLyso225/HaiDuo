# 阶段一验收门槛与结果

阶段一可演示业务闭环验收已通过，详细范围、证据和未完成项见[PHASE_ONE_REPORT.md](PHASE_ONE_REPORT.md)。全项目严格验收尚未通过，阶段二、三未开始。

| 范围 | 实际证据 | 首版边界 |
|---|---|---|
| 登录、成员、权限 | 登录/退出、CSRF、四角色、成员创建、最后管理员、跨企业、Redis重启恢复 | 邮件邀请/密码找回未实现 |

| 履约 | 手工运单与库存同事务，浏览器通过 | 不含真实承运商/轨迹事件 |
| 利润 | 原币费用/汇率来源时间快照，398.00样例 | 全部明确为预估，实际结算未实现 |
